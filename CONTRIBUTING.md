# Contributing

Growzilo uses repository-specific documentation as the source of truth.

## Working rules
- Open an issue for material work before implementation when practical.
- Keep accepted company/product decisions in `Growzilo/Handbook`.
- Keep implementation details in the repository that owns the work.
- Prefer small, reviewable pull requests.
- Update documentation when behavior or an accepted decision changes.
- Never weaken quality, security, privacy or evidence standards merely to make a check pass.
- Never commit client credentials, API keys, OAuth tokens, passwords, private lead/customer exports, payment data or production secrets.
